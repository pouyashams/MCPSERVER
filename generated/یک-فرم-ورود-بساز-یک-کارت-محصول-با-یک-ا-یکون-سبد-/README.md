<h1>خروجی رابط کاربری DIG</h1>

<h2>درخواست کاربر</h2>
<p>• یک فرم ورود بساز.

<h2>توضیح کوتاه محصول</h2>
<p>یک صفحهٔ جمع‌وجور راست‌به‌چپ شامل فرم ورود (ایمیل و رمز)، یک کارت محصول با دکمهٔ افزودن به سبد (آیکون سبد خرید) و یک دکمهٔ پرداخت در پاصفحهٔ کارت (آیکون کارت اعتباری). تمام کامپوننت‌ها از DIG MCP و آیکون‌ها از Digche گرفته و SVGها مستقیماً از get_icon_svg وارد شده‌اند.</p>

<h3>بررسی RTL</h3>
<p>تأیید شد - The rendered wrapper element includes dir=&quot;rtl&quot; (top-level &lt;div dir=&quot;rtl&quot; className=...&gt;). DIG documentation requires lang=&quot;fa&quot; and dir=&quot;rtl&quot; on &lt;html&gt; for full app setup, but when component-level control is used the explicit dir=&quot;rtl&quot; wrapper produces correct RTL layout. Additionally, the Input component MCP implements its own per-field dir resolution (resolvedDir) and uses logical Tailwind utilities (ms-*, me-*, ps-*, pe-*) internally. Code uses ms-2 for icon spacing (logical start) and does not use ml-/mr- which would break RTL. get_component input.tsx also documents dir behavior and logical utilities.</p>

<h3>بررسی Design Tokenها</h3>
<p>تأیید شد - Code uses semantic DIG tokens/classes such as bg-background, bg-card, text-muted-foreground, text-card-foreground, and Button uses color=&quot;primary&quot; which maps to DIG CSS variables via buttonVariants. The MCP component files (button.tsx, input.tsx, card.tsx) reference and expect these tokens/variables (e.g., --btn, --field, bg-card, text-card-foreground). No hard-coded arbitrary color hex values were introduced in the code; tokens are used consistently.</p>

<h2>چرا MCP از مستندات ساده قدرتمندتر است؟</h2>
<p>MCP فقط متن مستندات را در اختیار Agent نمی‌گذارد، بلکه ابزار قابل فراخوانی و ساختاریافته در زمان اجرا فراهم می‌کند. Agent می‌تواند موجودی واقعی کامپوننت‌ها و آیکون‌ها را هنگام انجام کار بررسی کند و به‌جای حدس‌زدن نام یا API، اطلاعات زنده محصول را دریافت کند. این رویکرد اتصال محصول به Agent را قابل‌کنترل‌تر، به‌روزتر و کم‌خطاتر می‌کند و می‌تواند قواعد دسترسی و عملیات واقعی محصول را نیز در همان قرارداد MCP ارائه کند.</p>
